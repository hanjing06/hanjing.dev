# Blog Post Template

All future blog posts on this site should follow the approved reference template from `/Users/hanjinglin/Documents/blog_template.pdf`.

## Required structure

1. `topic name - date`
2. `blog title`
3. Large hero image
4. Opening body copy with no heading before it
5. One or more repeated content sections, each introduced by a heading
6. Final `sign off` section

## In-repo implementation

- Reusable component: `/Users/hanjinglin/hanjing.dev/app/components/BlogPostTemplate.tsx`
- Visual reference page: `/Users/hanjinglin/hanjing.dev/app/blog/template/page.tsx`

## Rules to keep consistent

- Keep the topic and date together above the title in uppercase kicker styling.
- Use a single prominent title.
- Include one large cover image directly below the title.
- Start with uninterrupted opening paragraphs before the first section heading.
- Separate major sections with consistent spacing and a divider.
- End every post with a short sign off instead of stopping abruptly.

## Recommended authoring flow

1. Copy the structure from `/Users/hanjinglin/hanjing.dev/app/blog/template/page.tsx`.
2. Replace placeholder content with the actual post metadata, hero image, intro, sections, and sign off.
3. Keep section naming flexible, but preserve the overall layout hierarchy.
